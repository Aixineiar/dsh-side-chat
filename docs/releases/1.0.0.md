# 1.0.0 — 侧边对话

首个公开发布：在右侧栏开一条临时对话，继承当前会话的已提交上下文，回答只留在侧栏、不写回主会话。
三种模式的约束落在**实现层**（宿主工具注册表），不是提示词自律。
完整变更见 [CHANGELOG](https://github.com/Aixineiar/dsh-side-chat/blob/v1.0.0/CHANGELOG.md#100--2026-11-10)。

## 三种模式

| | **只回复** `reply` | **只读** `read`（默认） | **完全继承** `full` |
|---|---|---|---|
| 可用工具 | 无 | 只读名单（默认 12 项） | 与主会话完全一致 |
| 请求里带的工具 schema | 不带（模型看不到任何工具） | 只有只读工具 | 全部 |
| 系统提示里的工具说明段 | 全部剥掉 | 只留「能调用的工具」对应的段 | 全部保留 |
| 写文件 / 执行命令 / 子代理 | 不存在 | 不存在 | 可以（受宿主权限与沙箱约束） |
| 单步工具配额 | 不适用 | 每步 1 次只读调用 | 无 |
| 收到修改请求时 | 输出「修改建议 · 待主会话执行」 | 同左，允许用那一步的读工具确认目标 | 先给计划，再只问一次「在本侧边会话执行，还是回主会话执行？」 |
| 适合 | 要一句结论、纯问答 | 读代码 / 查历史后回答 | 在侧栏试改、验证命令 |

这一版里模式是**新建时的属性**：换模式会新开一条侧边对话并关闭当前这条。从 1.2.0 起可以在页签顶栏就地切换。

## 安装

- 插件管理器里输入包名 `@aixineiar/dsh-side-chat`（底层走 pnpm 从 npm 安装，并自动写进 profile 的 `dsh.profile.bundles`）；
- 或命令行：`pnpm add @aixineiar/dsh-side-chat`，然后手动把包名加进该 profile `package.json` 的 `dsh.profile.bundles`；
- 也可以用仓库地址 `github:Aixineiar/dsh-side-chat` 或本地目录 `link:/path/to/dsh-side-chat`。

环境：DSH 0.2.2-rc.1、Node ≥ 20。装完重启 DSH。

## 验证

`npm test` —— 自包含的引导模拟（用 stub 加载两半，不起 DSH）加客户端交互测试：三模式渲染的封闭名单等于实际下发的掩码、不可掩码的工具会被 guard 拒绝并记日志、边界标记带线程 id 与模式、种子保留事件信封字段、只读配额按步生效、拒绝文案形状一致、畸形 prompt 内容不会进日志。

## 已知限制

- **只读配额按「步」计**：一条消息的每一步各给一次只读机会，不是整轮一次。
- **快照不跟进**：打开后主会话的新进展不会自动出现；需要时点「以最新快照新开」（会关闭当前侧栏对话）。
- **需要主会话在线**：主会话未在左侧打开时无法打开侧边对话。
- **关闭即删除**：日志与目录一起删，没有回收站。
- **完全继承的风险由宿主的权限与沙箱决定**：本插件不额外收紧 `full` 的能力。

## 安全

工具裁剪由宿主工具注册表完成（`restrict` + `guard`），模型即使无视提示词也拿不到被裁掉的工具。所有控制动作走 `POST /dsh-side-chat/api`，先经宿主连接层鉴权；关闭前校验「这条会话确实是本插件创建的线程」。每个拒绝返回稳定错误码，页面只渲染本地字典里的句子。
