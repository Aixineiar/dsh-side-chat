# 1.2.0 — 就地切换模式

侧边对话的模式现在**可以随时就地换**：同一个 Agent、同一段历史，不新开、不关闭、已生成的回答都还在。
完整变更见 [CHANGELOG](https://github.com/Aixineiar/dsh-side-chat/blob/main/CHANGELOG.md#120--2026-11-14)。

## 新增

### 就地切换

页签顶栏左侧的模式标签就是切换按钮（`只读 ▾`），点开是同一份三选一菜单：

- 切换的是**这一条**侧边对话，不新建、不关闭，会话内容一个字都不丢；
- 切完立刻生效：工具清单按新模式在下一轮请求里重新下发，宿主的工具栏提示会显示「新增 N 个，移除 M 个」；系统提示段在下一步换成新模式；
- 重复选当前模式不发任何请求、不写任何消息；
- 地址里没记模式的老页签不显示这个按钮，仍只显示「上下文截至 …」，不猜。

入口卡片（工具面板里的「侧边对话」）右侧的 `⌄` **仍然是新建**：那里选模式会新开一条并关闭当前这条。就地切换在页签顶栏。

### 切换会告诉模型「规则变了」

每次切换固定往会话里写两条 user 消息，顺序固定：

1. 一行过渡提示 —— `模式已切换：只读 → 完全继承。上一条模式的说明作废，以下一条为准。`
2. 新模式的完整说明（和打开时那条同一个生成器）。

两条一起进入下一步的输入，最后读到的那条说明就是当前规则。过渡提示用独立的标记，并且刻意避开 `模式：<label>` 这一固定开头，所以日志扫描与旧版本的文本兜底都不会把它读成模式定义。

**代价要说清楚**：这两条消息永久留在这条会话的上下文里。切得越勤，占的上下文越多 —— 所以过渡提示只有一行。

### 插件页设置

「插件」页本插件的表单（`plugins.bundle.config`，键为包名）多了两项：

| 设置 | 默认 | 说明 |
|------|------|------|
| 显示右上角快捷按钮 | 开 | 关掉后头部按钮即时注销；工具面板的卡片照常可用 |
| 新会话的默认模式 | 跟随上次手动选择 | 只回复 / 只读 / 完全继承，或沿用你上次在卡片里挑的那个 |

两者都是**页面级设置**（`localStorage['dsh.side-chat.settings']`）：不写 profile、不走宿主路由、不需要重启，改完即时生效。

### 状态栏改用宿主原生组件

模式标签与「以最新快照新开」都换成宿主注入的 `@deepseek-ai/dsh-client-ui-primitives`：

- `Button`（`size: 'sm'`、`variant: 'ghost'`）——原来 36px、`padding: 0 14px` 的大框没了；
- `Tooltip`（下方、200ms、portal）——不再是浏览器原生 `title` 提示；
- 行内只压度量（18px 高、6px 内边距、11px 字），颜色/圆角/hover/焦点环仍来自共享组件。

不装包、不加运行时依赖。

## 修复

- **换地址不再 dispose 线程。** `openResource(address, { replaceTab: true })` 会关闭被替换的页签，并在**同一个调用里同步执行**注册的关闭处理器 —— 那个处理器会 dispose Agent、删除日志，也就是删除正在切换的那条会话。现在换地址被一层 `reAddressed` 守卫包住，普通关闭仍照旧。
- **旧宿主不再沉默。** 如果运行中的 Host 还没有 `mode` 动作，页面会明确写「宿主还是旧版本：重载插件或重启 DSH 后再切换」，而不是一句通用的「操作失败」；失败提示也从状态栏最右端挪到了模式按钮旁边。

## 升级须知

- **Host 半有改动**：重载插件或重启 DSH。页面刷新一次即可拿到新的 `client.js`（插件是 `link:` 安装时刷新即生效）。
- **上下文成本**：每次切换两条消息，永久留在该会话里。
- **飞行中的那一轮**沿用已经组装好的系统提示段；工具遮罩与 guard 立即生效，新模式的说明落在下一步。
- **老页签**（地址里没有 `m=`）保持原文案、不显示切换按钮。

## 安装 / 升级

插件管理器里输入包名即可，或按 README 的命令行方式：

```bash
cd <DSH_HOME>/profiles/<profile>
pnpm add @aixineiar/dsh-side-chat@1.2.0
```

命令行安装时记得把 `@aixineiar/dsh-side-chat` 加进该 profile `package.json` 的 `dsh.profile.bundles`。

- 运行环境：DSH 0.2.2-rc.3、Node ≥ 20
- 只读名单与部署配置（`allow` / `deny`）仍走 profile 的 `cordis.patch.yml`
- 离线测试：Host 220 条断言、Client 16 条交互级断言，全绿
